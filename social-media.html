The Open-Source Engines

Three real, third-party projects. Each belongs to its own authors under its own license — available on GitHub today.

📨

Postiz

AI social media scheduling tool supporting many platforms with native publishing and AI integration. One of the most popular open-source schedulers on GitHub.

License: AGPL-3.0

github.com/gitroomhq/postiz-app ↗

Crosspost

JavaScript utility by Nicholas C. Zakas for posting across multiple social networks — X, Bluesky, Mastodon, LinkedIn, Discord, and more.

License: ISC

Social Media Agent

LangChain agent for sourcing, curating, and scheduling social media posts with human-in-the-loop validation.

github.com/langchain-ai/social-media-agent ↗

Honest Quick Start

You can run the engines yourself today, straight from their upstream repositories. Each has its own setup docs.

# Each engine is a separate upstream project — clone and follow its README
git clone https://github.com/gitroomhq/postiz-app
git clone https://github.com/humanwhocodes/crosspost
git clone https://github.com/langchain-ai/social-media-agent

# Platform API keys are required per network (X, LinkedIn, etc.)
# Setup and supported platforms are documented in each repo's README
