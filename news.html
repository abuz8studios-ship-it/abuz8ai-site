How this page gets its data

No fabricated numbers, no fake urgency, no invisible tracking. Here is exactly where every number on this page comes from and what happens when a feed goes down.

  1. Public sources only

    GitHub's public trending pages, the public GitHub REST API, and the public Hugging Face API. We never scrape private data and never claim anyone's work as ours — every card links to its author.

  2. Server-side aggregation

    Two Cloudflare Pages Functions do the work: /api/github-trending parses GitHub's weekly and monthly trending pages (GitHub has no official trending JSON API), and /api/github-agents pulls live star counts for 20 curated open-source agent projects.

  3. Edge caching — kind to upstream

    Trending is cached about 1 hour, agent stars about 30 minutes, at Cloudflare's edge. That keeps the boards fresh without hammering anyone's servers.

  4. Honest fallbacks, always labeled

    If the trending parse fails, you get a real frozen snapshot captured 2026-05-24, labeled "cached snapshot." If GitHub rate-limits the star board, affected rows fall back to last-known cached counts and the board says so. If Hugging Face is unreachable, you get a labeled feed-offline note — never an invented number, never an empty broken board.

  5. One fetch per tab, zero polling

    Each tab loads its feed once, the first time you open it. Nothing auto-refreshes in the background. Reload the page when you want fresh data.

🟢 Privacy: this page sets no tracking cookies and sends nothing about you to our servers. The Hugging Face request goes straight from your browser to huggingface.co. The only data this site ever collects is what a visitor chooses to submit to the waitlist form.
🧭 Full disclosure: ABUZ8 has no public GitHub org and no public Hugging Face models today. Open-sourcing components and publishing sovereign models are both Roadmap items — the boards above showcase other people's excellent work, credited.

FAQ

Is the data on this page live?
Yes, when the feeds are reachable. The GitHub boards come from our Cloudflare Pages Functions, edge-cached for about 1 hour (trending) and 30 minutes (agent stars). Hugging Face trending is fetched by your browser directly from the public Hugging Face API. When a feed cannot be reached, the board says so honestly — a labeled cached snapshot or a feed-offline note, never a fabricated number.
Why do I sometimes see a "cached snapshot" label?
GitHub has no official JSON API for its trending page, so we parse the public trending pages server-side. If the upstream page is unreachable or its markup changes, we serve a real frozen snapshot captured 2026-05-24 and label it clearly, so you never see a broken or empty board.
Does this page auto-refresh or poll?
No. Each tab fetches its feed once, the first time you open it. There is no background polling and no auto-refresh. Reload the page to pull fresh data.
Are the models and repos on these boards ABUZ8 projects?
No. Everything on the boards belongs to its authors — we aggregate, credit, and link out to every source. ABUZ8's own Hugging Face account currently has no public models; publishing sovereign models and datasets is on our roadmap.
Do you track visitors on this page?
This page sets no tracking cookies and sends nothing about you to our servers. Feed requests go to our public API endpoints and to the public Hugging Face API. The only data this site ever collects is what a visitor submits to the waitlist form.
