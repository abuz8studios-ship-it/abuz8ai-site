The three categories of upscaler (and what each actually does)

1. Bicubic / Lanczos (the classics)

Math-based interpolation, no AI. Smooths existing pixels into a larger grid. Output looks like a blurry version of the original at higher resolution. Free, instant, suitable only when you need a small bump (1.5x-2x) and the source is already sharp.

2. ESRGAN family (what we use)

Trained neural networks that hallucinate plausible high-frequency detail. Specific models: 4x-UltraSharp for photos and renders, 4x_NMKD-Siax for anime and illustration, RealESRGAN_x4plus as a general-purpose default. These are open-source, fast, and good enough for most production work.

3. Diffusion-based upscalers (the latest wave)

Stable Diffusion upscale, SUPIR, Topaz Gigapixel AI's newer modes. These don't just upscale — they regenerate fine detail using a diffusion model. The output can look stunning. It can also "creative-write" details that weren't in the source, which is a problem for photographs of real people.

The decision tree

If the source is a photo of a real person: stick with 4x-UltraSharp or RealESRGAN. Diffusion upscalers will alter facial features.

If the source is AI-generated artwork: use a diffusion upscaler with low denoise strength (0.2-0.3) for best detail enhancement.

If the source is a logo or text: avoid AI entirely. Use a vector tracer like Inkscape's Trace Bitmap.

If the source is old film or scanned print: 4x-UltraSharp with face-restoration enabled.

Real numbers from our pipeline

Speed and quality on consumer GPU (RTX 4070):

  • 1024px → 4096px with 4x-UltraSharp: 8 seconds. Excellent quality. The workhorse.
  • 1024px → 4096px with SUPIR: 90 seconds. Best quality on artwork. Overkill for photos.
  • 512px → 2048px with RealESRGAN: 3 seconds. Great for batch processing.

For comparison, Topaz Gigapixel AI costs $99 and produces output roughly comparable to 4x-UltraSharp, with a slightly nicer UI. The model itself is not meaningfully better. You're paying for the interface.

The workflow that works for client deliverables

Three-pass workflow we use for converting any low-res source into a print-ready asset:

Pass 1: Clean up the source

Before upscaling, remove obvious artifacts. JPEG compression noise. Color cast. Visible film grain. The upscaler will faithfully amplify whatever you feed it, including the problems. Five minutes in Photoshop or GIMP saves you a re-do.

Pass 2: 2x with the right model

Use the decision tree above to pick the model. Run a 2x pass first. Inspect at 100%. If you see weird artifacts, change models.

Pass 3: Final 2x

Run the same image through another 2x pass. Two cascaded 2x upscales beat a single 4x pass on quality, because each stage has more pixels to work with than the last.

Total: 16-second job. Output: 4x linear scale (16x area). Suitable for prints up to 24"x36" at 300 DPI.

Where upscaling fails (and how to spot it)

Common failure modes:

  • Skin smoothing — the model averages out skin texture into plastic-looking surfaces. Use face-restoration models specifically (CodeFormer, GFPGAN) for portraits.
  • Hair waxiness — fine hair turns into clumped strands. Try a lower denoise strength or a different model.
  • Text glitching — letterforms become illegible. Don't upscale text. Recreate it.
  • Repeated patterns — fabric textures, foliage, brick walls can tile in unnatural ways. Generally a sign you upscaled too aggressively in one pass.
