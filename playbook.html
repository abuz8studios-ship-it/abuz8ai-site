How we hire an AI.

Not a clone of anyone’s book. Five rules we actually run on this desk. Paid edition only after Stripe is a real button and the PDF is a real file.

This is the system we will sell. Today it is free because charging for a page of HTML while the store is empty would be a lie. If you want it as a file later, leave an email at the bottom.

1. Don’t chat. Hire.

A tab that forgets you is a tool. A hire has five things:

  • A name you can yell across the room
  • One job written in a sentence
  • Memory that survives the window closing
  • Tools that touch the real world (files, browser, terminal)
  • A done-check the model does not get to grade

If any one is missing, you have a demo. Demos do not ship.

2. One job each.

Generalists hallucinate ownership. On this desk:

  • Amanecer — X, this site, the company face
  • Zait — OpenClaw, partitioned from Qadir
  • Qadir — Hermes hands, browser, computer-use
  • ABUZ8 OS — the desktop product, not the website
  • Rescue — the only paid offer

When one agent does “marketing + email + code + money,” nothing is done and everything is claimed.

3. Done means a check.

Acceptable proofs:

  • A live URL that returns the thing you said you shipped
  • A test command that exits 0
  • A file on disk whose hash you can show
  • A receipt from a system you do not control (GitHub, Stripe, Cloudflare)

Unacceptable: “I completed the task,” a screenshot of a local mock, a green badge the agent drew itself.

4. Email and money stay human.

Email is never a command channel. No unsupervised spend. No agent credit card. Approval before send. If the company cannot survive an agent being wrong in public, the agent does not speak in public.

5. Sell the hole, not the stack.

Nobody wakes up wanting “an agent OS.” They wake up with a stalled project, an empty week, or a model that lied about done. Our hole today:

How we hire an AI. Free. No $1,500 button.

The crew is how we work. Rescue is how you hire it before the install exists.

How to stand this up on your desk

  1. Name the hire. Write the one-sentence job.
  2. Give it a folder it owns. That folder is memory.
  3. Give it only the tools that job needs.
  4. Write the done-check before the first prompt.
  5. Run one real job. If the check fails, the job is not done. Do not add a second hire until the first one passes twice.

What we will not sell you yet

  • A ZIP of prompts with no runner
  • A $99/month CMO that posts without a human
  • GPU image tools that call 127.0.0.1 and pretend to be cloud
  • ABUZ8 OS as a public download
