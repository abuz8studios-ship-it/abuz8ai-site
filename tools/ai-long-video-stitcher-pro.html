How the pipeline works

01

Shot breakdown

In Script-to-Film mode, AI uses storyboard_breakdown to decompose your script into individual shots — scene type, camera angle, duration, visual mood, and key action per shot.

02

Parallel rendering

Each shot is queued into ComfyUI as an independent generation job. All shots render in parallel on the RTX 5090, then a completion gate waits for the full set before stitching begins.

03

Stitch + score

comfyui_stitch_long handles clip assembly with transition compositing. comfyui_music generates a synchronized original score using AudioCraft, timed to the edit rhythm.

04

Final export

Output is a single H.264 MP4. 1920×1080 or 1080×1920. Your script and footage never touch external servers. Private. Watermark-free. Download link available for 24 hours.
